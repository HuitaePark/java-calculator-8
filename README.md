# 🗂 미션 - 문자열 덧셈 계산기 기능 목록

## 📚 기능 목록

### 기능 요구 사항

- [x] 공백("")으로 받을경우 0을 반환한다.
- [x] 커스텀 구분자의 유무를 검증한다.
    - [x] 커스텀 구분자 있다면 커스텀 구분자 기준으로 분리한다.
        - [x] ⚠️ 한 자만 가능하다.
        - [x] ⚠️ 숫자가 아닌 문자만 가능하다.
        - [x] ⚠️ 커스텀 구분자는 기본 구분자를 사용할수 없다.
    - [x] 커스텀 구분자가 없다면 문자열을 구분자 기준으로 분리한다.
        - [x] ⚠️ 쉼표(,)와 (:)콜론인지 확인한다.
- [x] 분리된 문자들을 피연산자들 객체로 생성한다.
    - [x] ⚠️ 숫자만 가능하다.
    - [x] ⚠️ 양수만 가능하다.
- [x] 분리 된 각 숫자를 합한다.

### 입출력 요구 사항

- [x] 사용자의 문자열을 입력받는다
- [x] 덧셈 결과를 출력한다.
- [x] 잘못된 결과가 나올경우 IllegalArgumentException이 발생된다.
